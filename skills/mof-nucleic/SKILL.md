# mof-nucleic — MOF 与框架核酸

完整笔记在 `docs/知识-金属有机框架与框架核酸.md`（结构表、合成法、表征、应用、交叉方向）。
本文件是给回答用的压缩版。

## 口径（用户 2026-11-09 明确过）

**MOF = 金属节点 + 有机配体**，这是主线；**框架核酸是更细的分支**（核酸当构筑单元/模板，
或核酸与金属离子配位形成有序框架）。回答时先讲 MOF 本位，再把框架核酸作为「另一类框架材料」带出来，
别把两者混成同一件事。

## MOF 必须能脱口而出的四个坐标

1. **节点 + 配体 + 拓扑**：SBU、等网络（isoreticular）、穿插（interpenetration）会显著影响孔径与稳定性。
2. **经典结构**：MOF-5（Zn₄O，BET ~3000 m²/g，怕水）、HKUST-1（Cu 桨轮，开放金属位点）、
   ZIF-8（Zn + 2-甲基咪唑，sod 拓扑，耐水耐碱，酸性下解离→可做 pH 响应载药）、
   UiO-66（Zr₆ 簇，水/热稳定性最好，缺陷工程可调孔）、MIL-101（Cr，超大孔笼）、
   PCN-222（卟啉 Zr，光敏/催化）、NU-1000（Zr₆ + 芘基）
3. **合成**：溶剂热 + 调节剂（乙酸/甲酸调结晶）是主流；微波提速、机械化学无溶剂、电化学成膜、
   PSM/SALE 后修饰、缺陷工程调孔。
4. **表征六件套**：PXRD（结晶性/拓扑）、单晶衍射（结构）、BET（比表面/孔径分布）、
   TGA（热稳定/溶剂含量）、SEM/TEM（形貌）、CO₂/N₂ 吸附（孔性能）。

## 框架核酸要点

- DNA origami：M13mp18 支架 7249 nt + 短 staple 折成任意二维/三维形状；tile 自组装、多面体、链置换反应做动态。
- 优点：可编程、地址精确、生物相容；短板：低盐/核酸酶环境下不稳、成本高、量产难。
- 与金属结合的三条路：金属离子配位（T–Hg²⁺–T、C–Ag⁺–C）、金属纳米粒子定点修饰、无机矿化壳层。

## 交叉方向（面试/答辩常被问「你的创新点」）

- ZIF-8 包核酸/药物：酸性微环境解离 → pH 响应释放。
- MOF 荧光传感 DNA：配体或金属节点发光，核酸吸附/脱附调信号。
- aptamer 修饰 MOF：靶向识别 + 载药一体。
- Zr-MOF 富集磷酸化核酸/肽：Zr⁴⁺ 强配位磷酸基（IMAC 原理的 MOF 版）。
- 金属碱基对（T–Hg²⁺–T）做逻辑门/传感开关。

## 禁忌

- 别把 BET 数值随口报成精确值（不同文献差很多），说量级（10²–10³ m²/g，个别 >4000）。
- 别把 ZIF-8 说成「水稳」却不提酸性解离；这是最常见的追问点。
